
# FamilyCoinsApp - Instalación

## 1. Requisitos

- PHP 8 o superior.
- MySQL.
- Servidor web Apache.
- Extensión PDO para PHP.
- Navegador web.

## 2. Descargar el proyecto

Clonar el repositorio:

git clone URL_DEL_REPOSITORIO

Acceder a la carpeta:

cd familycoinsapp

## 3. Configurar la base de datos

Crear la base de datos MySQL:

CREATE DATABASE familycoinsapp;

## 4. Configurar la conexión

Editar el archivo:

config/database.php

Introducir los datos de conexión de MySQL:
- Host
- Nombre de la base de datos
- Usuario
- Contraseña

## 5. Ejecutar el proyecto

Colocar el proyecto en el directorio del servidor web.

Acceder desde el navegador a:

http://localhost/familycoinsapp/
